# SlotBook

SlotBook is a planned resource-booking platform for managing shared meeting rooms and equipment within an organization. It aims to let users discover available resources, check real-time availability, and reserve them without conflicts, while giving administrators oversight and control over the resource pool.

## Status

**Planning** — implementation has not started. This repository currently contains only project documentation.

## Intended Stack

- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## Planned Capabilities

The following capabilities are planned for future implementation:

- Resource discovery (browsing meeting rooms and shared equipment)
- Availability search (finding free time slots for a given resource)
- Booking management (creating, viewing, and cancelling reservations)
- Role-based access (distinguishing permissions between regular users and administrators)
- Prevention of double booking (ensuring a resource cannot be reserved for overlapping time slots)
- Admin dashboard (overseeing resources, bookings, and users)

No architecture, API design, or implementation decisions have been made yet.
